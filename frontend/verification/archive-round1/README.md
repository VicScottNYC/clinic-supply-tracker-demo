# Archive: round 1 accessibility screenshots

These screenshots were captured before the final accessibility fixes on the P1 interface
(Receive line labels, row-toggle buttons, focus outlines, dark-mode button contrast, and
phone-width layout). They are kept only as history. They do not show current behaviour.

Current evidence is in `../a11y/` and in `mac-a11y-evidence/`.
`reflow640-` images are a 640 CSS px viewport (reflow), not browser zoom.
Actual 200% zoom was checked manually on the Mac; see `frontend/ACCESSIBILITY.md`.
